Satu sistem untuk seluruh proses bisnis bakery.

BakeERP menghubungkan pembelian bahan, persediaan, produksi berbasis resep (BOM), penjualan kasir, dan laporan keuangan dalam satu basis data. Satu transaksi cukup diinput sekali, lalu mengalir otomatis ke seluruh modul terkait.

ℹ️
Catatan: halaman ini hanya profil proyek, bukan aplikasinya.

BakeERP adalah aplikasi full-stack (server Python + basis data). GitHub Pages hanya dapat menyajikan berkas statis, sehingga aplikasi interaktifnya tidak bisa berjalan di sini. Untuk mencoba aplikasi yang sesungguhnya, jalankan di komputer Anda dengan langkah pada bagian Cara Menjalankan — seluruh kode dan data contoh sudah tersedia di repositori.

12 halaman fungsional, 6 modul terintegrasi

Bukan mockup — setiap halaman terhubung ke basis data dan benar-benar mengubah data.

01

Dashboard

KPI penjualan harian, laba bersih, nilai persediaan, peringatan stok kritis, dan tren 7 hari.

02

Penjualan (POS)

Keranjang, diskon, tiga metode bayar. Stok produk berkurang dan HPP dihitung dari resep.

03

Produksi

Validasi ketersediaan bahan sebelum produksi, lalu bahan berkurang dan produk jadi bertambah.

04

Pembelian

Purchase order ke supplier. Penerimaan barang menambah stok dan memperbarui harga rata-rata.

05

Master Data & Resep

Bahan baku, produk, supplier, dan bill of material penentu HPP per unit.

06

Keuangan & Laporan

Buku kas, laba rugi otomatis, laporan penjualan, produksi, dan posisi persediaan.

Integrasi antar modul

Inilah yang membedakan ERP dari sekumpulan aplikasi terpisah: tidak ada input data berulang.

Pembelian bahan→ Stok bahan naik→ Produksi sesuai resep→ Stok produk jadi naik→ Penjualan (POS)→ HPP & pendapatan→ Buku kas & laba rugi
TransaksiEfek pada persediaanEfek pada keuangan
Terima POStok bahan bertambah; harga rata-rata diperbaruiKas keluar sebesar nilai PO
ProduksiBahan berkurang sesuai resep; produk jadi bertambahBiaya bahan tercatat sebagai dasar HPP
PenjualanStok produk jadi berkurangKas masuk; pendapatan dan HPP tercatat
PengeluaranTidak berubahKas keluar; menurunkan laba bersih
Ubah resepTidak langsung berubahMengubah HPP seluruh transaksi berikutnya

Cara menjalankan

Hanya butuh Python 3.10+. Tidak ada paket yang perlu dipasang untuk mode bawaan.

1. Ambil kode

git clone https://github.com/lyradelia-commits/bakerp-erp.git
cd bakerp-erp

2. Jalankan

python app.py
# Windows: bisa juga klik dua kali
# "Mulai BakeERP.bat"

3. Buka browser

http://localhost:8000

Akun demo

UsernamePasswordPeran
adminadmin123Admin / pemilik
gudanggudang123Gudang & produksi
kasirkasir123Kasir

Basis data bakery.db sudah berisi data contoh 31 hari (534 penjualan, 185 batch produksi, 560 baris kas), jadi dashboard dan laporan langsung terisi saat pertama dibuka.

Mode MySQL (opsional)

python migrate_to_mysql.py
BAKERP_BACKEND=mysql python app.py
